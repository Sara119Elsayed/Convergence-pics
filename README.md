## Moving Pics

Refactored "Moving Pics" demo added here with external CSS and JS files.

Files:
- `Moving Pics.refactored.html` — refactored HTML linking the assets
- `moving-pics.css` — styles with improved layout and controls
- `moving-pics.js` — interaction: play/pause, speed slider, reset

Usage:
1. Open `Moving Pics.refactored.html` in a browser.
2. Use Play/Stop/Reset and adjust the Speed slider.

To push these changes to GitHub, create an empty repo on GitHub and follow:

```bash
git remote add origin <your-repo-url>
git branch -M main
git push -u origin main
```
